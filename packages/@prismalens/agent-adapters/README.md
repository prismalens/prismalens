# @prismalens/agent-adapters

The ACP adapters PrismaLens ships so that an installed `claude` or `codex` is all a user needs,
pinned to the versions PrismaLens tested. It is published to npm by hand as
[`@prismalens/agent-adapters`](https://www.npmjs.com/package/@prismalens/agent-adapters), with the
adapters bundled and no native agent binaries. See https://prismalens.io.
