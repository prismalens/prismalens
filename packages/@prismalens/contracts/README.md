# @prismalens/contracts

@prismalens/contracts defines shared domain schemas, event definitions, and API route contracts for PrismaLens. It provides typed Zod schemas for system entities, canonical investigation event streams, and oRPC procedure definitions used across the frontend, API, worker, and CLI packages. This ensures type safety and contract consistency across all services.

Product documentation and API references are available at https://docs.prismalens.io.
